# SAEH Travel — website v1

A responsive Arabic/French travel-agency landing page. Static HTML, CSS and JavaScript; no build step or runtime dependency is required.

## Local preview
Open `index.html` in a modern browser.

## Cloudflare Pages
Upload the contents of this folder to the existing Pages project root. The project currently uses a root output directory and no build command, so no framework configuration is needed.

## Before public launch
- Set the official WhatsApp business number in the WhatsApp links and booking form. Current links open WhatsApp with a prefilled message but do not target a specific business number.
- Replace illustrative destination photography with licensed images selected for the brand.
- Add verified business contact details, company/legal information, and actual package availability/pricing.
- Test all booking flows and mobile layouts on real devices.

The destination cards are editorial inspiration, not confirmed offers or live inventory.
