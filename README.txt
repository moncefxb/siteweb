SAEH TRAVEL — STATIC WEBSITE DEMO
=================================

Files
- index.html: complete responsive, static demo website.

Languages
- Arabic (RTL)
- French (LTR)
- English (LTR)

Language picker
- Click the language name in the header to open the language menu.
- The selected language is remembered in the browser when local storage is available.

Demo-only details
- SAEH Travel is used as a fictional sample brand.
- Destination prices, trip lengths, address, phone number, email and testimonials are illustrative placeholders.
- The trip form only displays a local preview. It does not send personal data, contact WhatsApp, store requests, accept payments or create bookings.
- Replace every demo detail and connect a real form/contact channel before using the site for a real travel agency.

Deploying on Cloudflare Pages
1. Upload the contents of this folder to your site repository or drag the folder into a supported static deployment workflow.
2. Keep index.html at the published site root.
3. No build command is required; this is a plain HTML/CSS/JavaScript site.

Notes
- Google Fonts and the Unsplash photos are loaded from external services, so an internet connection is needed for those visual assets.
- The site has no backend, database, authentication or payment integration.
